 descrição

aplicativo desenvolvido com React Native e Expo, contendo:

- estrutura inicial "Hello World" com `View` e `Text`.
- contador interativo utilizando o hook `useState`.
- botões para Incrementar, Decrementar (sem valores negativos) e Zerar.
- botões customizados com `TouchableOpacity`.

 Como executar
bash
npm install
npx expo start


escaneie o QR Code com o app Expo Go*no celular, ou pressione `w` no terminal
para abrir no navegador.

 branches

`main`: código base do projeto.
`pratica-01`: implementação dos desafios extras da Prática 01.
